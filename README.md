# Princess Events — demo website

Site static HTML/CSS/JS, pregătit pentru Visual Studio Code / VS Code.

## Pornire
1. Deschide folderul în VS Code.
2. Deschide `index.html` în browser sau folosește extensia Live Server.
3. Toate fotografiile sunt în `assets/`.

## Înainte de publicare
Înlocuiește textele demo cu informațiile reale:
- capacitatea exactă pentru Princess / Palace / Queen
- telefon, email și adresă
- meniurile și prețurile
- recenziile reale
- fotografiile finale
- datele sociale
- formularul de contact cu un serviciu real de trimitere

Designul este responsive pentru desktop, tabletă și mobil.
